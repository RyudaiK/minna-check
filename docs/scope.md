# プロダクトスコープ

## エレベーターピッチ

朝の時間がすれ違う共働き家庭向けの、家族の必須タスク共有ボードです。
「誰がやったか」を記録するだけでなく、「まだ誰もやっていない」ことも家族に見えるため、確認の電話や二重実施を減らし、誰でも安心してタスクを引き受けられます。家族 LINE、TimeTree、紙のチェックリストとは違い、やった人は「やったよ」をワンタップするだけで、現在の未完了状態と実施履歴を共有できます。

## ユースケース

### 1. 家族が今日の未完了タスクを確認する

- 家族のメンバーがアプリを開く
- 今日の必須タスクと進捗（例: 2/4 済）を見る
- 「まだ」と表示されたタスクを確認し、自分が実施するか判断する

### 2. 家族のメンバーがタスクを実施してワンタップで知らせる

- メンバーが未完了のタスクを実施する
- 対象タスクの「やったよ！」をタップする
- 家族全員の画面に完了状態、実施者、時刻が反映される

### 3. 実施前に二重実施を避ける

- メンバーがタスクを始める前にアプリを確認する
- すでに完了していれば、実施者と時刻を確認して重複を避ける
- 未完了なら、自分が実施してから記録する

### 4. 締切前に未完了タスクを家族へ知らせる

- 締切時刻が近づく
- 未完了のタスクだけが家族全員に通知される
- 通知を見たメンバーがタスクを実施し、ワンタップで完了を共有する

## 作らないもの（今回のPoC）

1. **汎用的なカレンダー／ToDo管理**
   - 予定の作成、期限管理、優先順位付けを広げず、「1日1回きりで欠かせない必須タスク」に集中する。
2. **家族向けチャットやコメント機能**
   - 会話は家族 LINE など既存ツールに任せ、アプリ内にはタスク状態の共有に必要な情報だけを置く。
3. **詳細な担当割り当て・シフト管理**
   - 誰が担当するかを事前に固定せず、未完了状態を見た人が引き受けられる設計にする。
4. **センサー・自動給餌器などによる実施の自動検知**
   - 入力ゼロの案は、ワンタップ運用が重いと分かった場合の次の検討事項とし、今回のPoCでは作らない。
5. **ネイティブアプリ版・店舗向けB2B版・高度な課金機能**
   - まずスマホブラウザで使えるWebアプリとして家族利用を検証し、iOS/Androidのネイティブアプリ化、動物病院・ペットホテル向け機能、課金は検証後に判断する。
